# Project Vision

Project Name

DailyKhata

Mission

Build the easiest ledger app for small shop owners and families.

Problem

Existing ledger apps have too many features.

Many elderly people

can't understand accounting

don't understand English

need only simple bookkeeping

forget where money went

Goal

Create an app that even a 55 year old shopkeeper who never used technology can use within 5 minutes.

Design Principles

Minimal UI

Very large buttons

One action per screen

No accounting knowledge required

Everything understandable with icons

Works offline

Fast

Zero learning curve

Primary Audience

Small shop owners

Parents

Household expense tracking

Local businesses

Secondary Audience

Students

Freelancers

Small startups
